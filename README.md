# Female Piglins Mod

A Minecraft mod that adds female piglins with different personalities. They can be befriended or romanced by interacting with them and giving them gold items.

## Features
- Female piglins with different personalities
- Interaction mechanics with gold items
- Simple GUI for interacting with female piglins

## Installation
1. Download the mod jar file.
2. Place it in the `mods` folder of your Minecraft installation.
3. Launch Minecraft with the Fabric loader installed.

## Usage
- Spawn female piglins in the Nether.
- Interact with them using gold items to befriend or romance them.
- Use the GUI to manage interactions.
